Add papers to CARESearch from your browser

Drag the button below to your browser’s bookmarks bar. On an article page, select the bookmark to detect the DOI and open a pre-filled CARESearch submission form.

Add to CARESearch
  1. Show your browser’s bookmarks bar.
  2. Drag Add to CARESearch onto it.
  3. Open a journal article page and select the bookmark.
  4. Check the detected DOI and submit the GitHub issue.
What happens next?

GitHub retrieves the article metadata and abstract, updates the dataset on a new branch, and creates a pull request for review. No GitHub token is stored in the bookmark.
