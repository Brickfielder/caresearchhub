# Adding a paper to CARESearch

## One-time setup

1. Open the CARESearch bookmark page and drag **Add to CARESearch** to your bookmarks bar.
2. On the first submission, enter your approved email address.
3. Open the confirmation link sent to that email. This confirms the browser for future use.

## Adding a paper

1. Open the journal article page in Chrome or Edge.
2. Select **Add to CARESearch** in your bookmarks bar.
3. Check that the detected DOI is correct and select **Submit for review**.
4. CARESearch fetches the available metadata and abstract, then creates a pull request for the editor to review.

If the DOI is not found automatically, paste it into the submission form. If you use a different browser or clear browser data, repeat the one-time setup.
